    Módulo 1: ¿Qué es JSON?

    | Un formato de texto para guardar y transferir datos
    20 min Teoría

    1.1Definición y estructura8 min

    JavaScript Object Notation

    JSON es un formato estándar basado en texto para almacenar y transferir datos entre sistemas. Aunque nació en JavaScript, hoy lo usan todos los lenguajes: APIs web, archivos de configuración, bases de datos documentales.

    Su estructura es muy parecida a la de Python: objetos con pares clave-valor (como un diccionario) y arreglos (como una lista). Las claves siempre van en cadenas con comillas dobles.

    Un objeto

    persona.json: un registro con legajo, nombre, apellido, edad y activo.

    Una lista de objetos

    paises.json: varios registros con la misma forma.

    Nota para el docente

    Abrí persona.json y paises.json en el explorador de la apertura. Pedí que digan “qué estructura de Python” es cada uno antes de ejecutar nada: dict y lista de dicts.

    JSON y Python: tabla de equivalencias

    JSONPythonEjemplo JSON
    objeto { }dict{"edad": 25}
    arreglo [ ]list[1, 2, 3]
    stringstr"Esteban" (solo comillas dobles)
    número entero / realint / float25, 3.14
    true / falseTrue / Falseen minúscula
    nullNonenull

    No existen en JSON: tuplas, conjuntos, comentarios ni claves numéricas. Más abajo vemos qué pasa con cada una.

    1.2Reglas de sintaxis: el laboratorio JSON12 min

    Laboratorio: ¿es JSON válido?

    Escribí o elegí un ejemplo. La página lo pasa por json.loads() y muestra el resultado en Python o el error exacto que daría tu programa.

    Nota para el docente

    Antes de tocar cada botón, preguntá: “¿Python lo acepta?”. La mayoría falla “Comillas simples” y “True de Python”, porque parecen un diccionario de Python. JSON no es Python: es un formato con sus propias reglas.

    Las cinco reglas que más se rompen

    • Strings y claves con comillas dobles: "nombre", nunca 'nombre'.
    • Literales en minúscula: true, false, null.
    • Sin coma después del último elemento.
    • Sin comentarios (# ni //).
    • Un solo valor raíz: un objeto, un arreglo, o un dato simple.
    Alerta de error típico: confundir un dict de Python con JSON

    print(diccionario) muestra {'nombre': 'Ana', 'activo': True}: eso no es JSON. Si copiás esa salida a un archivo .json, al leerlo vas a obtener un JSONDecodeError. Para producir JSON válido usá siempre json.dumps() o json.dump().

    2.1Serializar con json.dumps()8 min

    De Python a JSON

    Serializar es convertir un objeto de Python en una cadena de texto con formato JSON. El resultado es un str: se puede imprimir, enviar por red o guardar.

    Al serializar, las claves del diccionario se convierten automáticamente en cadenas y los valores se traducen según la tabla de equivalencias.

    Nota para el docente

    Este es el ejemplo 00_serializacion_deserializacion.py del material. Hacé notar las dos líneas impresas: parecen iguales, pero una tiene comillas simples (dict) y la otra dobles (str).

    import json

# Serialización: convertir objeto Python a JSON
data = {
    "nombre": "Carlos",
    "apellido": "Garcia",
    "edad": 35,
    "ciudad": "Madrid"
}
json_string = json.dumps(data)

print("Serialización (dumps) - Python a JSON:")
print(data, type(data))                 # comillas simples: es un dict
print(json_string, type(json_string))   # comillas dobles: es un str
print(json_string[0:12])                # al ser str, se puede cortar como texto

    2.2Deserializar con json.loads()6 min

    De JSON a Python

    Deserializar es el camino inverso: tomar una cadena con JSON y obtener un dict o una list de Python. Recién ahí podés acceder por clave, recorrer y modificar.

    Fijate en la traducción: true pasa a True.

    Alerta de error típico: acceder a una clave sin deserializar

    Si tenés el JSON en una cadena, data_json["nombre"] lanza TypeError: string indices must be integers: todavía es texto, no un diccionario. Primero json.loads().

    import json

# Deserialización: convertir objeto JSON a Python
print("Deserialización (loads) - JSON a Python:")
data_json = '{"legajo": 123456, "nombre": "Esteban", "apellido": "Suárez", "edad": 25, "activo": true}'
datos_python = json.loads(data_json)

print(data_json, type(data_json))         # str: true en minúscula
print(datos_python, type(datos_python))   # dict: True de Python
print(datos_python["nombre"])             # Esteban -> ahora sí, acceso por clave

print(data_json["nombre"])                # TypeError: todavía es texto

    2.3Parámetros útiles y conversiones sorpresa11 min

    indent, ensure_ascii y sort_keys

    ParámetroQué hace
    indent=4Agrega saltos de línea y sangría: el archivo queda legible para personas.
    ensure_ascii=FalseConserva á é í ó ú ñ tal cual, en lugar de \u00e1.
    sort_keys=TrueOrdena las claves alfabéticamente.

    En los archivos de la materia vamos a usar siempre ensure_ascii=False, indent=4, como en el ejemplo del CRUD.

    Alerta de error típico: datos que cambian al ir y volver
    • Las claves numéricas vuelven como texto: {1: "a"} → {"1": "a"}. Después, d[1] da KeyError; hay que usar d["1"].
    • Las tuplas vuelven como listas.
    • Los conjuntos no se pueden serializar: TypeError: Object of type set is not JSON serializable. Convertilos antes con list() o sorted().
    import json

alumna = {1: "primer año", "nombre": "Analía", "materias": ("Álgebra", "Programación")}

print(json.dumps(alumna))                       # tildes como \u00e1
print(json.dumps(alumna, ensure_ascii=False))   # tildes legibles
print(json.dumps(alumna, ensure_ascii=False, indent=4))

# Ida y vuelta: ¿queda igual?
vuelta = json.loads(json.dumps(alumna))
print(vuelta)                  # la tupla es lista y la clave 1 es "1"
print(vuelta == alumna)        # False
print(vuelta["1"])             # primer año -> la clave ahora es str

# Conjuntos: convertir antes de serializar
etiquetas = {"python", "json"}
print(json.dumps(sorted(etiquetas)))     # ["json", "python"]
print(json.dumps(etiquetas))             # TypeError: set no es serializable

    3.1Guardar: de Python a un archivo .json8 min

    json.dump(objeto, archivo)

    dump se traduce como volcar: vuelca el contenido de una variable de Python en un archivo con formato JSON. El archivo tiene que estar abierto en modo escritura.

    ModoSignificadoSi el archivo existe
    "r"Lectura (por defecto)Lo lee. Si no existe: FileNotFoundError
    "w"EscrituraLo vacía y escribe desde cero
    "a"Agregar al finalEscribe a continuación (no sirve para JSON)

    Este es el ejemplo 01_convertir_a_JSON.py, con la apertura y el cierre manual que muestra el material.

    Alerta de error típico: except: sin tipo y el close() que falla

    Si open() falla, la variable archivo nunca se crea y el archivo.close() del finally lanza NameError. Por eso el ejemplo necesita un segundo try adentro del finally. La declaración with resuelve los dos problemas de una vez.

    import json

stock = {"item1": 100, "item2": 200, "item3": 300}
try:
    archivo = open("archivos/stock.json", "w")
    json.dump(stock, archivo)   # colocamos el contenido
                                # de la variable en el archivo
    print("Stock guardado")
except:
    print("No se pudo abrir el archivo")
finally:
    try:
        archivo.close()
    except Exception as e:
        print(f"No se pudo cerrar el archivo correctamente: {e}")
    import json

stock = {"item1": 100, "item2": 200, "item3": 300}

# Con with, el archivo se cierra SOLO, aunque ocurra un error
try:
    with open("archivos/stock.json", "w", encoding="UTF-8") as archivo:
        json.dump(stock, archivo, ensure_ascii=False, indent=4)
    print("Stock guardado con with")
except OSError as e:
    print("No se pudo guardar:", e)

    3.2Leer: de un archivo .json a Python8 min

    json.load(archivo)

    load lee todo el archivo y lo convierte a Python. El tipo resultante depende del contenido: paises.json empieza con [, así que obtenemos una lista que en su interior contiene diccionarios.

    Siempre que el archivo pueda tener tildes o eñes, abrilo con encoding="UTF-8": en Windows, sin ese parámetro, “Suárez” puede leerse como “SuÃ¡rez”.

    Alerta de error típico: abrir con "w" lo que querías leer

    open(ruta, "w") borra el contenido en el mismo momento en que se abre, antes de escribir nada. Si después intentás json.load() sobre ese archivo, ya está vacío. Leé con "r", modificá en memoria y recién al final abrí con "w" para guardar.

    import json

ruta_archivo = "archivos/paises.json"
try:
    with open(ruta_archivo, "r", encoding="UTF-8") as archivo:
        paises = json.load(archivo)   # lista de diccionarios
    print(type(paises), type(paises[0]))
    for pais in paises:
        print(f'{pais["id"]}: {pais["nombre"]}')
except FileNotFoundError:
    print("No existe el archivo", ruta_archivo)
except json.JSONDecodeError as e:
    print("El archivo no tiene JSON válido:", e)
    import json

    3.3Recorrer estructuras: diccionario de diccionarios y anidados9 min

    Tres formas de organizar un JSON

    Lista de objetos

    paises.json, empleados.json: se recorre con for item in lista.

    Objeto de objetos

    productos.json: la clave es el ID. Se recorre con for id, p in d.items().

    Anidado

    users.json: objetos dentro de objetos. Se accede encadenando claves.

    En users.json, la calle de un usuario está en user["address"]["street"] y la latitud en user["address"]["geo"]["lat"]. Cada corchete baja un nivel.

    Alerta de error típico: las claves del archivo vienen como texto

    En productos.json los IDs son "1", "2"… (JSON no admite claves numéricas). productos[1] da KeyError: 1. Si el usuario escribe un número, convertilo a texto: productos[str(id_producto)].

    Nota para el docente

    El ejemplo de usuarios usa users.json de JSONPlaceholder, la API de prueba más usada en cursos: es el mismo formato que devuelve una API real, así que conecta con la materia de web scraping y APIs.

    import json

def mostrar_productos(ruta_archivo):
    try:
        with open(ruta_archivo, "r", encoding="utf-8") as archivo:
            productos = json.load(archivo)    # diccionario de diccionarios
        print("-" * 80)
        print(f'{"ID":<5} {"Descripción":<25} {"Presentación":<20} {"Marca":<15} {"Precio":>6}')
        print("-" * 80)
        for id_producto in productos:         # recorre las CLAVES ("1", "2"...)
            p = productos[id_producto]        # el diccionario interno
            print(f'{id_producto:<5} {p["Descripcion"]:<25} {p["Presentacion"]:<20} {p["Marca"]:<15} ${p["Precio"]:>5}')
    except Exception as e:
        print(f"No se pudo procesar el archivo: {e}")

mostrar_productos("archivos/productos.json")
    import json

    Módulo 4: CRUD con JSON y errores típicos

    | Leer, modificar en memoria y sobrescribir
    25 min Teoría + práctica

    4.1El patrón de las tres fases5 min

    Un archivo JSON no se edita “por partes”

    No se puede cambiar una línea de un archivo JSON como en una planilla. Toda operación de alta, baja o modificación sigue siempre el mismo ciclo:

    1. Leerjson.load()archivo → lista en memoria
    2. Modificarappend / pop / [i][k] = vlos cambios ocurren en RAM
    3. Sobrescribirjson.dump()memoria → archivo completo

    Create (alta), Read (listado), Update (modificación) y Delete (baja): las tres últimas letras usan las tres fases; el listado, solo la primera.

    Nota para el docente

    Dibujá las tres cajas en el pizarrón y, durante todo el módulo, señalá en qué fase está cada línea del CRUD. El error más común en el proyecto es olvidar la fase 3: el programa “funciona” mientras está abierto y los cambios desaparecen al cerrarlo.

    Estado inicial de empleados.json

    Abrilo en el explorador antes de ejecutar el CRUD. Después de correrlo, volvé a mirarlo: el archivo cambió. Si querés repetir la demostración, tocá Restaurar archivos.

    4.2El CRUD completo, paso a paso12 min

    Recorrido por las funciones

    FunciónFasesLo importante
    agregar_datos1 · 2 · 3Calcula el legajo nuevo con max(...) + 1, valida la edad con while True + try y agrega con append().
    mostrar_datos1Solo lee y formatea con f-strings de ancho fijo (:<10).
    modificar_datos1 · 2 · 3Busca el índice con una lista auxiliar de legajos y index().
    eliminar_por_legajo1 · 2 · 3Mismo buscador, y pop(indice) para quitar.

    Las Datos de entrada de este bloque reproducen la ejecución del material: alta de Fernando Segovia, edad de Analía a 46 y baja de Esteban (legajo 123456). Probá cambiarlas en la consola, por ejemplo con un legajo inexistente o una edad con letras.

    Alerta de error típico: f-strings con las mismas comillas adentro

    El material original tiene print(f'Se ha agregado a {nuevo_empleado['nombre']}'): comillas simples afuera y adentro. Funciona en Python 3.12 o superior, pero en 3.11 o anteriores es un SyntaxError. En la versión de esta página se usan comillas dobles afuera y simples adentro, que funciona en cualquier versión.

    Alerta de error típico: pedir datos antes de validar que existe

    modificar_datos pide la nueva edad antes de comprobar que el legajo existe: si no existe, el usuario cargó un dato para nada. Una mejora simple es verificar primero el legajo y recién después pedir la edad. Es un buen ejercicio de refactorización para el proyecto.

    import json

# Agregar datos
def agregar_datos(archivo):
    try:
        with open(archivo, 'r', encoding="UTF-8") as datos:
            empleados = json.load(datos)  # 1) LEER: cargar el contenido existente

        # Obtener el legajo más alto y sumar 1
        if empleados:
            nuevo_legajo = max(emp["legajo"] for emp in empleados) + 1
        else:
            nuevo_legajo = 1  # Si la lista está vacía, comenzamos desde 1

        # Solicitar los datos al usuario
        nombre = input("Ingrese el nombre: ").strip().capitalize()
        apellido = input("Ingrese el apellido: ").strip().capitalize()
        while True:
            try:
                edad = int(input("Ingrese la edad: "))
                break
            except ValueError:
                print("Por favor, ingrese un número válido para la edad.")

        while True:
            activo_input = input("¿Está activo? (s/n): ").strip().lower()
            if activo_input in ["s", "n"]:
                activo = True if activo_input == "s" else False
                break
            else:
                print("Respuesta no válida. Ingrese 's' o 'n'.")

        # 2) MODIFICAR EN MEMORIA: crear el nuevo empleado
        nuevo_empleado = {"legajo": nuevo_legajo, "nombre": nombre, "apellido": apellido, "edad": edad, "activo": activo}
        empleados.append(nuevo_empleado)

        # 3) SOBRESCRIBIR el archivo con los datos actualizados
        with open(archivo, 'w', encoding="UTF-8") as datos:
            json.dump(empleados, datos, ensure_ascii=False, indent=4)
        print(f"Se ha agregado a {nuevo_empleado['nombre']} {nuevo_empleado['apellido']}")

    except (FileNotFoundError, OSError, json.JSONDecodeError) as error:
        print(f'Error! {error}')

# Listar datos
def mostrar_datos(archivo, modo):
    try:
        with open(archivo, modo, encoding="UTF-8") as datos:
            empleados = json.load(datos)
            print("\nLISTADO DE EMPLEADOS")
            print(f'{"Legajo":<10}{"Apellido y nombre":<30}{"Edad":<6}{"Estado":<10}')
            for emp in empleados:
                nombre_completo = f"{emp['apellido'].upper()} {emp['nombre']}"
                activo = "Activo" if emp['activo'] else "Inactivo"
                print(f"{emp['legajo']:<10}{nombre_completo:<30}{emp['edad']:<6}{activo:<10}")
    except (FileNotFoundError, OSError, json.JSONDecodeError) as error:
        print(f'Error! {error}')

# Modificar un dato (cambiar la edad de un empleado)
def modificar_datos(archivo, legajo):
    try:
        with open(archivo, 'r', encoding="UTF-8") as datos:
            empleados = json.load(datos)
        # Pedir la nueva edad antes
        while True:
            try:
                nueva_edad = int(input("Ingrese la nueva edad: "))
                break
            except ValueError:
                print("Por favor, ingrese un número válido.")

        # Verificar si el legajo existe usando 'in' en una lista de legajos
        legajos = [emp["legajo"] for emp in empleados]
        if legajo in legajos:
            indice = legajos.index(legajo)          # posición del empleado
            empleados[indice]["edad"] = nueva_edad
            with open(archivo, 'w', encoding="UTF-8") as datos:
                json.dump(empleados, datos, ensure_ascii=False, indent=4)
            print(f"Edad del empleado con legajo {legajo} modificada a {nueva_edad} años.")
        else:
            print(f"Empleado con legajo {legajo} no encontrado.")
    except (FileNotFoundError, OSError, json.JSONDecodeError) as error:
        print(f'Error! {error}')

# Eliminar datos (por legajo)
def eliminar_por_legajo(archivo, legajo):
    try:
        with open(archivo, 'r', encoding="UTF-8") as datos:
            empleados = json.load(datos)
        legajos = [emp["legajo"] for emp in empleados]
        if legajo in legajos:
            indice = legajos.index(legajo)
            empleados.pop(indice)  # Elimina el empleado por índice
            with open(archivo, 'w', encoding="UTF-8") as datos:
                json.dump(empleados, datos, ensure_ascii=False, indent=4)
            print(f"Empleado con legajo {legajo} eliminado.")
        else:
            print(f"Empleado con legajo {legajo} no encontrado.")
    except (FileNotFoundError, OSError, json.JSONDecodeError) as error:
        print(f'Error! {error}')

# Programa principal
mostrar_datos("archivos/empleados.json", "r")
agregar_datos("archivos/empleados.json")

legajo = int(input("Legajo a modificar: "))
modificar_datos("archivos/empleados.json", legajo)

legajo = int(input("Legajo a eliminar: "))
eliminar_por_legajo("archivos/empleados.json", legajo)
mostrar_datos("archivos/empleados.json", "r")

    4.3Errores típicos al trabajar con archivos JSON8 min

    Qué excepción esperar en cada caso

    SituaciónExcepción
    La ruta no existe o tiene un error de tipeoFileNotFoundError
    El archivo existe pero está vacío o tiene JSON inválidojson.JSONDecodeError
    Sin permisos, disco lleno, ruta a una carpetaOSError
    Se intenta guardar un set u otro objeto no compatibleTypeError
    Se busca una clave que no está en el registroKeyError

    FileNotFoundError es un caso particular de OSError. Si querés un mensaje distinto para cada uno, el except FileNotFoundError tiene que ir antes.

    Alerta de error típico: el archivo vacío o corrupto

    Un archivo .json recién creado y vacío no es una lista vacía: json.load() lanza JSONDecodeError: Expecting value. Inicializalo con [] o {}. En el explorador está archivos/roto.json, con una coma de más, para practicar.

    import json

def cargar(ruta):
    try:
        with open(ruta, encoding="UTF-8") as f:
            return json.load(f)
    except FileNotFoundError:
        print(f"[{ruta}] no existe")

    import json

RUTA = "archivos/stock.json"

def registrar_venta(ruta, item, cantidad):
    with open(ruta, encoding="UTF-8") as f:
        stock = json.load(f)
    if item not in stock:
        raise KeyError(item)
    if cantidad <= 0:
        raise ValueError("la cantidad debe ser positiva")
    if cantidad > stock[item]:
        raise ValueError(f"stock insuficiente (hay {stock[item]})")
    stock[item] -= cantidad                     # recién ahora se modifica
    with open(ruta, "w", encoding="UTF-8") as f:
        json.dump(stock, f, indent=4)
    return stock[item]

        print(f"OK   {item} -{cant} -> quedan {queda}")
